## Pendientes personales antes de entregar

Registrar dos ensayos cronometrados y tres recorridos manuales, grabar video y añadir enlace, revisar las respuestas de defensa, entregar el informe PDF en el aula. No se han inventado registros de estas actividades. Los commits conservan sus fechas reales: el requisito de tres días diferentes no se obtiene alterando fechas. La etiqueta v1.0-demo debe señalar la versión revisada para la exposición del 19 de noviembre, sin mover una etiqueta publicada.
